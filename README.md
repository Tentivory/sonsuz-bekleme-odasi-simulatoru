# SonSUz BeKLeMe OdAsı SiMüLaTöRü

## Resmi Açıklama

Bu repository, insanlık tarihinin en büyük sorununa çözüm üretmek amacıyla kurulmuştur: **Bekleme**.

Evet, bekleme. O sonsuz, anlamsız, ruh öldürücü bekleme. Artık beklemek için bir simülatöre ihtiyacınız var. Çünkü gerçek hayatta zaten yeterince bekliyorsunuz ama bu daha eğlenceli.

### Özellikler

- Gerçekten çalışır (Python 3+)
- Zamanınızı çalar
- Absürt mesajlar verir
- Hiçbir işe yaramaz
- %100 Türkçe (bürokrasi tadında)
- Çıkış yoktur (aslında vardır ama yok gibi)

### Kurulum ve Kullanım

```bash
git clone https://github.com/Tentivory/sonsuz-bekleme-odasi-simulatoru.git
cd sonsuz-bekleme-odasi-simulatoru
python3 bekleme_simulatoru.py
```

Sonra bekleyin. Gerçekten bekleyin. Sonra daha da bekleyin.

### Uyarı

Bu programı çalıştırmak, gerçek hayattaki bekleme sürelerinizi kısaltmaz. Aksine, artırır. Kullanım sonucu oluşacak varoluşsal krizlerden sorumlu değiliz.

### Katkıda Bulunma

Pull request göndermeyin. Bekleyin.
